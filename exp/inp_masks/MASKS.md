# Channel H Matrix — Evaluation Mask Set

The H matrix is **64×64** (N_tx × N_rx = 4096 entries).  
Mask value `1` = observed, `0` = missing.  
All masks use `seed=0` for reproducibility.

Generated by `generate_all_masks.py` (11 files), which calls `generate_mask()` from `generate_channel_mask.py`.  
Note: `random_32x32.npy` serves double duty — it is both the moderate-density entry in Group A and the random-grid baseline in Group B.

---

## Design Rationale

Two independent axes structure the set:

### Axis 1 — Observation density
Controls task difficulty.  Three levels:

| Level | Entries | Density |
|-------|---------|---------|
| Sparse | ~64–256 | ~1.6–6.3% |
| Moderate | 1024 | 25% |
| Dense | 2048 | 50% |

The **25% level** is the primary comparison point because it is realistic for pilot-based channel acquisition while still leaving substantial missing information.

### Axis 2 — Spatial structure
Controls the physical/protocol scenario being modelled:

| Mode | Physical scenario |
|------|------------------|
| `random` | Random selection of (Tx, Rx) grid intersections — a measurement campaign where you choose which tx/rx pairs to probe |
| `block` | Contiguous sub-array — a spatially localised portion of the array is available (e.g., one panel) |
| `random_rows` | Full transmitter rows are observed — models Tx-side antenna failure or selection; all Rx links for those Tx are known |
| `random_cols` | Full receiver columns are observed — symmetric to rows, models Rx-side failure/selection |
| `periodic` | Every k-th Tx and every k-th Rx — regular pilot grid, analogous to OFDM pilot patterns |
| `random_entries` | Individual (Tx, Rx) links chosen independently at random — maximum spatial disorder, no row/column structure; theoretical baseline for unstructured sparsity |

The **Group B** masks all sit at exactly 25% density but use different structures, making them directly comparable for isolating structure effects from density effects.

## Mask Catalogue

### Group A — Density sweep (random grid structure)
*Purpose: measure how NMSE and cosine similarity degrade as fewer antennas are observed.*

| Filename | Mode | Params | Entries | Density |
|----------|------|--------|---------|---------|
| `random_8x8.npy` | random | 8 Tx × 8 Rx | 64 | 1.6% |
| `random_16x16.npy` | random | 16 Tx × 16 Rx | 256 | 6.3% |
| `random_32x32.npy` | random | 32 Tx × 32 Rx | 1024 | 25.0% |

### Group B — Structure comparison at 25% density
*Purpose: isolate the effect of spatial structure on reconstruction quality.*

| Filename | Mode | Params | Entries | Density | Rationale |
|----------|------|--------|---------|---------|-----------|
| `random_32x32.npy` | random | 32×32 grid | 1024 | 25% | Baseline structured sparsity |
| `block_32x32.npy` | block | top-left 32×32 | 1024 | 25% | Hardest: missing entries are a contiguous unknown region |
| `rows_16.npy` | random_rows | 16 full rows | 1024 | 25% | Tx-side partial observation; provides complete Rx coverage per observed Tx |
| `cols_16.npy` | random_cols | 16 full cols | 1024 | 25% | Rx-side partial observation; symmetric to rows |
| `periodic_s2.npy` | periodic | step=2 | 1024 | 25% | Uniform pilot grid — structured but globally distributed |
| `entries_25pct.npy` | random_entries | ratio=0.25 | 1024 | 25% | No row/col structure — hardest for any row/col-aware method |

### Group C — 50% upper-bound reference
*Purpose: show best-case performance when half the H matrix is observed.*

| Filename | Mode | Params | Entries | Density |
|----------|------|--------|---------|---------|
| `rows_32.npy` | random_rows | 32 full rows | 2048 | 50% |
| `cols_32.npy` | random_cols | 32 full cols | 2048 | 50% |
| `entries_50pct.npy` | random_entries | ratio=0.5 | 2048 | 50% |

## Suggested Experiment Workflow

```bash
# Generate all masks
python exp/inp_masks/generate_all_masks.py

# Run DDNM for each mask (example: all 25% masks)
for MASK in random_32x32 block_32x32 rows_16 cols_16 periodic_s2 entries_25pct; do
    python main.py \
        --config channel_hq.yml \
        --path_y channel_data \
        --deg inpainting \
        --simplified \
        --mask_path exp/inp_masks/${MASK}.npy \
        --image_folder results/${MASK}
done
```
